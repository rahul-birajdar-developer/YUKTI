# YUKTI (युक्ति)

## A Collaborative Coding and Learning Platform for College Students

**Tagline:** Think. Code. Collaborate.

## 1. Introduction

YUKTI is a web-based collaborative coding and learning
platform designed primarily for college students.

The platform provides an integrated environment where
students can learn programming concepts, solve coding
problems, collaborate with other students in real-time
coding rooms, review solutions and track their learning
progress.

The main goal is to improve programming knowledge,
problem-solving abilities and collaborative learning.

## 2. Problem Statement

Many students use different platforms for learning
programming, practising coding problems and collaborating
with friends.

These activities are often separated across multiple
platforms, making it difficult for students to manage
their learning activities and monitor their improvement.

YUKTI aims to bring these learning activities together
in one platform.

## 3. Project Objectives

- Provide a structured programming learning environment.
- Allow students to practise coding problems.
- Support real-time collaborative coding.
- Enable students to explain and review solutions.
- Track individual coding performance.
- Help students identify areas for improvement.

## 4. Target Users

- College students
- Coding club members
- Programming learners
- Faculty members (future scope)
- Placement preparation students

## 5. Main Modules

1. Student Authentication
2. Student Dashboard
3. Programming Learning Library
4. Individual Coding Practice
5. Collaborative Coding Rooms
6. Solution Explanation and Peer Review
7. Learning Progress Analytics
8. Mock Interview Practice (future scope)

## 7. Project Scope

The initial version focuses on student registration,
programming practice, collaborative coding rooms,
solution reviews and progress tracking.

Advanced features such as AI-powered learning assistance
and advanced mock interviews may be considered in future
versions.

## 8. Expected Outcome

The expected outcome is a functional web application
that provides college students with a structured
environment for programming practice, collaboration
and learning progress tracking.
